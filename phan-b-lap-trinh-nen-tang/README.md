# Phần B — Lập trình nền tảng & Logic (Giai đoạn 25–52)

**Trạng thái: đang hoàn thiện** — khung nội dung chi tiết từng giai đoạn có sẵn trong [ROADMAP.md](../ROADMAP.md); học liệu đầy đủ sẽ phát hành theo thứ tự sau Phần A.

## Mục tiêu phần

Chuyển từ ngôn ngữ khối (Scratch) sang ngôn ngữ văn bản thật — **Python** — và xây dựng nền móng toán học tư duy cho AI: logic boolean, thuật toán kinh điển, nhị phân, xác suất, tọa độ. Kết thúc phần, người học viết được chương trình hoàn chỉnh (biến, điều kiện, vòng lặp, hàm, danh sách, từ điển, tệp), hiểu được ba thuật toán kinh điển, và có một trang web cá nhân đầu tiên.

## Đối tượng & tiên quyết

- Đối tượng: học sinh THCS đầu cấp (lớp 6–7), học sinh cuối tiểu học năng lực cao.
- Tiên quyết: Phần A — đặc biệt tư duy thuật toán (GĐ 02, 05–06) và trải nghiệm Scratch (GĐ 09–16).

## Kết quả đầu ra chính

1. Ứng dụng CLI hoàn chỉnh: trò chơi đoán số (GĐ 33), quản lý chi tiêu (GĐ 44).
2. Bộ sưu tập hoa văn turtle graphics và mô phỏng xác suất (GĐ 40, 50–51).
3. Trang web HTML/CSS giới thiệu bản thân (GĐ 46–47).
4. Portfolio "Lập trình viên tập sự" (GĐ 52) — gạch đầu tiên cho hồ sơ GitHub cá nhân.

## Ghi chú triển khai

- Môi trường: Python 3.10+ cài đặt tại máy hoặc Google Colab; giáo viên nên chuẩn bị trước 1 "thư viện lỗi vui" (tập hợp thông báo lỗi quen thuộc) để bớt sợ lỗi ngay buổi đầu.
- Nhịp: 2 buổi x 45 phút / giai đoạn; mỗi buổi có ít nhất 60% thời gian viết code thực tế.
- Kết nối GDPT: củng cố trực tiếp môn Toán THCS (số học, tỷ lệ, xác suất) và môn Tin học (thuật toán, lập trình).
