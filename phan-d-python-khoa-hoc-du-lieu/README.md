# Phần D — Python Khoa học dữ liệu (Giai đoạn 77–100)

**Trạng thái: đang hoàn thiện** — khung nội dung chi tiết từng giai đoạn có sẵn trong [ROADMAP.md](../ROADMAP.md); học liệu đầy đủ sẽ phát hành theo thứ tự sau Phần C.

## Mục tiêu phần

Chuyển sang công cụ của người làm dữ liệu thật: **Git/GitHub, NumPy, Pandas, Matplotlib, Seaborn** cùng nền thống kê cần thiết để hiểu dữ liệu và không bị dữ liệu "lừa". Kết thúc phần, người học có một báo cáo phân tích dữ liệu end-to-end trên GitHub: từ câu hỏi → làm sạch → phân tích → trực quan hóa → kết luận.

## Đối tượng & tiên quyết

- Đối tượng: học sinh cuối THCS – đầu THPT (lớp 9–10); người tự học đã qua Phần B–C.
- Tiên quyết: Python nền tảng (Phần B), khái niệm dữ liệu và bảng (Phần C).

## Kết quả đầu ra chính

1. Repo GitHub đầu tiên với README, cấu trúc dự án chuẩn (GĐ 78–79).
2. Notebook phân tích dữ liệu bán hàng hoàn chỉnh (GĐ 87) và dashboard dữ liệu Việt Nam (GĐ 92).
3. Nền thống kê: trung vị vs trung bình, phân phối chuẩn, mẫu–tổng thể, tương quan ≠ nhân quả, kiểm định giả thuyết nhập môn (GĐ 93–98).
4. Báo cáo end-to-end (GĐ 100) — gạch đầu tiên của hồ sơ "Nhà phân tích dữ liệu tập sự".

## Ghi chú triển khai

- Dùng dữ liệu Việt Nam thật khi có thể (giá rau chợ, kết quả thể thao, khí hậu) — giữ nguyên tắc "dữ liệu gần gũi" từ Phần A.
- Biểu đồ bắt buộc hiển thị đúng tiếng Việt (font) từ GĐ 89 — chi tiết kỹ thuật nhỏ nhưng là "dấu hiệu người làm thật".
